Customer Churn Prediction

A machine learning project focused on predicting customer churn for a subscription-based service using historical customer data, including usage behavior and demographic features.

Features
Data preprocessing and exploratory analysis
Customer behavior and demographic analysis
Churn prediction using Logistic Regression, Random Forest, and Gradient Boosting
Model evaluation using classification metrics
Tech Stack
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Jupyter Notebook / Google Colab
Objective

Develop a reliable model to identify customers likely to churn and support data-driven customer retention strategies.
